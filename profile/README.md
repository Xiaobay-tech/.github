### 关于我们

**Xiaobay-tech** 是一个聚焦计算机视觉与端侧部署的技术组织。我们围绕视觉算法、YOLO、Android、C++ 和嵌入式系统，沉淀工程实践，分享可复用的组件与开发工具。

### 探索方向

| ◎ 视觉与 YOLO | ◇ Android 与 C++ | ⌘ 嵌入式与开源工具 |
| :--- | :--- | :--- |
| 从图像理解到目标检测 | 从算法能力到端侧应用 | 从边缘设备到可复用工具 |
| 检测与识别、模型训练、部署实践 | 多媒体处理、高性能推理、底层能力 | 资源受限场景、设备集成、开发工具 |

### 从原型到落地

**01 / 视觉算法** &nbsp; → &nbsp; **02 / 推理部署** &nbsp; → &nbsp; **03 / 端侧应用**

围绕完整工程链路，关注算法如何运行在设备上，以及实践如何被整理、复用与分享。

### 一起探索

欢迎关注组织，获取后续开源仓库与技术更新。你可以通过 [Issues](https://github.com/Xiaobay-tech/.github/issues) 交流技术方向、提出建议；具体项目的问题与贡献，请前往对应仓库。

**From Vision to Devices.**

Xiaobay-tech focuses on computer vision and on-device deployment, sharing engineering practice from algorithm prototypes to Android and embedded systems.

- **Android & C++** — on-device applications, multimedia pipelines, high-performance inference, and low-level systems.
- **Embedded & Open Source Tools** — edge devices, resource-constrained environments, reusable components, and developer tooling.
