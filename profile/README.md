**From Vision to Devices.**

Xiaobay-tech focuses on computer vision and on-device deployment, sharing engineering practice from algorithm prototypes to Android and embedded systems.

- **Computer vision** — detection, recognition, YOLO, model training, and deployment.
- **On-device engineering** — Android applications, C++, multimedia pipelines, and high-performance inference.
- **Embedded & open source** — edge devices, resource-constrained environments, reusable components, and developer tooling.
